# 视觉风格全站审计（2026-08-11）

> 范围：全部可见页面、按钮、控件、排版、颜色、动效、无障碍。
> 方法：①代码盘点全部 UI 组件与 styles.css；②联网调研 Apple 复刻项目 / 前端审美理论 / 交互理论；③对照审计并落地。
> 调研来源：Apple HIG（developer.apple.com）、Ionic iOS 主题、Framework7 iOS 主题、Material Design 3 官方 token、Tailwind v4 / shadcn / Radix Themes、Refactoring UI、NN/g 响应时间研究、W3C WAI-ARIA / WCAG 2.2。

## 一、调研结论 → 本项目规范（token 级）

| 维度 | 调研依据 | 落地值 |
|---|---|---|
| 主按钮圆角 | Ionic iOS：14px / 大 16 / 小 6 | 12px（主按钮族统一） |
| 主按钮高度 | HIG 最小 44pt 点击目标 | start 48 / primary 44 |
| disabled | Ionic：opacity 0.4 共识区间 0.3–0.5 | 统一 opacity 0.4 |
| 分段控件 | Framework7 iOS：容器灰底、选中白底 + 阴影 | 容器 color-mix 黑 7%/白 10%，选中 0 2px 2px rgba(0,0,0,0.2) |
| 开关 | iOS 51×31pt、轨道圆角 16 | 51×31、thumb 27、开=var(--success) |
| 输入框 | HIG：44pt 高、圆角 10、focus 3px ring | radius 10、高 ~44px、focus ring 保留 |
| 弹窗 | Material：scrim 32%、入场 150–250ms | overlay fade 0.2s、content fade+scale 0.25s |
| 圆角档位 | M3 shape：控件 ≤ 卡片 ≤ 浮层 | sm 6 / md 10 / lg 12 / xl 14，胶囊 9999 |
| 间距 | 4pt 底 / 8pt 节奏 | 4/8/12/16/24/32/48，规整 10→8/12、14→16 |
| 动效 | press 100ms / hover 150ms / enter 200–300ms | press 0.1 / hover 0.15 / enter 0.2–0.3 |
| 图标 | Lucide：stroke 2、24 网格 | 尺寸档 14/16/18/20/24，currentColor |
| toast | iOS 无 toast 惯例，用顶部横幅/内联 | 改为顶部横幅（唯一用途：撤回确认） |
| 空状态 | HIG：给下一步行动入口 | 流水账空态加图标+描述+回今天 |

## 三、结构性问题修复

1. 合并 8 组重复定义：`.seg-item`、`.ambient-item`、`.pill-dot`、`.finish-actions`、`.withdraw-btn`、`.timeline-head`、`.now-line`、`.finish-glow`
2. 删除死代码：`.gap-line`、`.nudge-btn`、`.nudge-icon`、`.rhythm-nudge`、`.auth-input`（组件已不使用）
3. 清理空注释块；CSS 注释改为分区标题

## 四、控件规范修正

- 主按钮族（.start-btn/.primary-btn）radius 统一 12px；primary 高 40→44
- .text-btn 高 30→32（对齐 32 刻度）
- 输入框 radius 8→10，padding 10px→11px（≈44px 高），intent/finish 字号统一 15px
- switch 44×26→51×31，thumb 22→27
- now 信标灰→accent 蓝线+呼吸点
- toast 底部居中→顶部横幅（top 16px、毛玻璃、radius 12）

## 五、交互与无障碍

- dialog overlay/content 入场动画（Radix data-state）
- PIN 删除键 disabled→aria-disabled（保留可聚焦，W3C 建议）
- 流水账空状态：图标+描述+「回今天」行动
- aria-live 审查：away-line=off（每秒变化不打扰）、toast=polite、banner=status，均合规
- focus-visible 全局 outline 2px accent（已合规）；reduced-motion 全局兜底（已合规）
