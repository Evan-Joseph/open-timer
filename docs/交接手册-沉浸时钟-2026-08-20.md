## 已实现的关键行为

1. 服务端时间是事实来源，前端用单调时钟平滑显示并重新校准。
2. 同一用户最多一个活动会话；暂停/继续段保持同一时间轴泳道。
3. 休息预算基于上一段专注时长：约为专注时长的 1/5，最少 2 分钟、最多 20 分钟；提醒阶段为 75%、100%、150%（具体阈值以 `shared/src/rest-policy.ts` 为准）。
4. 专注运行中不触发离开提醒；暂停和科目结束后才进入休息状态；午饭、午睡、晚饭、夜间等静默窗口不升级提醒。
5. 近 7 天只展示已结束段，固定 08:00–22:30 全天泳道；打开 7 天视图时隐藏单日时间轴。
6. 7 天视图和全屏时间轴已针对真实累积数据做过固定视口回归；全屏抽屉打开后使用真实网格行，不依赖固定负位移。
7. 时间轴片段支持悬停预览、点击详情、备注编辑、起点补录、撤回/作废；事件链保留审计记录。
8. 全屏当前由浏览器状态自动识别；现状已有外部进入全屏后的布局切换，但应用内“进入全屏”入口尚未按本次要求恢复。

## 当前审计重点

### P0：先保护的契约

- 任何 UI 改动不得改变 `subject_id`、历史 session、统计和 API 字段兼容性。
- 不得让 `ended_at: null` 的 running/paused 开放段出现在近 7 天泳道。
- 不得在 running 状态显示休息提醒；paused/结束反馈才允许显示休息预算和逾期阶段。
- 不得让撤回、起点补录、暂停/继续后的时间轴和日报出现不同步。
- 不得重新引入 `.workers.dev` 作为产品 Base URL；公开文档统一使用 `clock.4c666.top`。
- 核对写请求幂等契约：`PATCH /sessions/:id/note`、`POST /retime`、`POST /adjust-start` 当前未统一经过 `withIdempotency`，但 README/API 文档写成“所有写请求必须携带 Idempotency-Key”。先用测试固定预期，再改实现或文档。
- 修正部署文档漂移：README 的迁移章节仍写“前端静态走 Pages”，当前生产配置实际是 Worker Static Assets，`ASSETS` 绑定并启用 `run_worker_first`。

### P1：本轮产品打磨

- 左上角“沉浸时钟”名称：评估隐藏、短品牌名或纯图标方案；需同时检查页面标题、ARIA、favicon/分享标题和测试选择器。
- 设置内恢复“进入全屏”按钮：使用熟悉的全屏图标，浏览器拒绝或权限失败时给出可理解反馈；外部 F11/DOM Fullscreen 仍自动识别。
- 建立单一视觉 token 表：背景、表面、边框、主色、危险色、文字层级、圆角、阴影、材质透明度、动效时长。禁止组件各自写一套近似值。
- 统一按钮层级：主操作、次操作、危险操作、图标操作、分段选择器、时间轴控制器分别定义尺寸和焦点态；图标按钮提供 tooltip/ARIA，不用文字圆角胶囊替代熟悉图标。
- 统一弹层透明度和层级：设置、时间轴详情、全屏抽屉不能互相套卡；检查 backdrop-filter 退化、深色模式对比度和滚动锁定。
- Pad/Desktop 横屏共用一套布局：至少验证 1024×768、1180×820、1280×720、1440×900；首屏不产生文档滚动，不遮挡时钟、休息提示、时间轴和当前时间 Flag。
- `playwright.config.ts` 仍保留 Pixel 7 mobile project；本轮产品要求不再投入移动端，接手者应确认是否退役该 project，Pad/Desktop 验收不能继续由手机项目代替。
- 文案精简：删除重复免责声明、无意义百分比、无法解释的同比指标；只保留能帮助当前决策的时长、状态、范围和动作。
- 动效统一：优先 CSS transition + `motion/react` 现有能力；每个状态切换定义进入、退出、布局位移和 reduced-motion 行为，不新增 GSAP 作为默认依赖。

### P2：前后端质量审计

- 检查公开只读 API 的数据最小化、缓存/ETag、CORS、错误响应和速率限制；确认备注等字段是否仍符合公开读取的产品决策。
- 检查 D1 与 SQLite adapter 行为一致性：事务、唯一活动会话、事件链、幂等响应清理、UTC 存储和 Asia/Shanghai 汇总。
- 检查静态资源 fallback：`run_worker_first`、API 404 与 SPA fallback 不得互相吞错；线上必须分别验证 API 和 `/`。
- 检查前端轮询、可见性恢复、多标签页 BroadcastChannel/localStorage 同步、后台节流后的服务端时间校准。
- 检查声音：浏览器 autoplay 解锁、默认音量、结束提示音和环境音启停；不得把系统/耳机的绝对响度写成应用可保证的事实。

## 参考资料与使用方式

本次 GitHub 检索结果中大量低 Star“Apple 仿作”和未维护模板不纳入规范来源。优先读原仓库源码、文档、Issue 和最近提交，再决定是否借鉴。
