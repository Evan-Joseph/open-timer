# 动效与交互升级 · 设计（2026-08-24）

> 目标：底层已扎实（时间轴/备注/三态氛围），补上"手感"与"事件感"——状态转换要有游戏感的即时反馈，休息提醒要从"太轻柔"升级为"无法忽视但不打断"。
> 约束（不变）：只用 CSS transition/关键帧 + 既有 motion/react，**不引 GSAP**（调研 GSAP/Awwwards 只为取技法）；`prefers-reduced-motion` 与 `html.animations-off` 全部降级为静态终态；循环动画频率 ≥2.4s（WCAG 2.3.1）；一次性动效 ≤0.9s；**时长只取 `--dur-*` token 档位**（e2e 白名单强制）；沿用既有语义 token（`--dur-*`/`--ease-*`/语义色）。
> 继承决策：不恢复阻断式弹窗（2026-08-21 移除）——升级走"氛围梯度 + 召唤入口"，不抢占焦点。

## A. 休息提醒升级（核心诉求："太轻柔"）

现状问题：L1→L2→L3 只有静态样式切换，**升级瞬间没有事件感**；逾期只有红洗色，没有"该做什么"的召唤。

| 项 | 设计 |
|---|---|
| A1 升级事件感 | `reminderLevel` 上升瞬间一次性触发：`.away-line.knock`（0.4s 横向敲击）+ `edge-flash`（全视口内缘 3px 光晕脉冲 0.9s，L2 琥珀 / L3 红）。key 递增重触发。声音梯度已有（L2/L3 各一次），保留。 |
| A2 回归专注召唤 | ~~`reminderLevel ≥ 2` 时 away 区出现 `.return-cta` 胶囊~~ **已移除（2026-08-25，用户决策：与开始/继续按钮语义重复）**。逾期召回改由洗色 + 敲击 + 升级音 + 既有开始/继续入口承担。 |
| A3 静默时段 | quiet 窗口维持 `reminderLevel=0`，不触发 A1/A2（既有逻辑不动）。 |

## B. 状态转换（游戏感一次性动效）

| 转换 | 动效 |
|---|---|
| 空闲/结束→运行（开始、继续这段） | `fx-ignite`：clockface 内缘 success 色光环 + 内发光一次性扫出（0.5s） |
| 运行→暂停 | `fx-settle`：0.5s 暗色帷幕掠过（配合既有 is-paused 降饱和） |
| 暂停→运行（继续） | `fx-recover`：0.5s accent 内发光回升 |
| 任意→结束 | 结束卡入场改弹簧曲线（0.28s 轻微过冲 1.15），`.finish-glow` 由呼吸改一次性绽放（0.9s） |

实现：`phaseNow`（idle/running/paused/finish）变化侦测 → `.clock-fx.fx-*` 覆盖层（key 重触发），无需手动清理。
