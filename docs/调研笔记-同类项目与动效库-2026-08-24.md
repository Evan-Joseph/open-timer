## 提炼的技法（含出处）

### 1. Pomotroid：token 纪律 + 派生色 + 进度环
- **转场时长 token**：`--transition-default 0.2s ease / --transition-snappy 0.12s cubic-bezier(0.4,0,0.2,1) / --transition-slow 0.35s ease`——与我们 `--dur-*` 白名单完全同一思想（e2e 强制），验证我们的纪律是业界正解。
- **color-mix 派生 chrome**：`--color-separator: color-mix(in oklch, foreground 8%, transparent)`——深浅主题零硬编码，我们已在用。
- **SVG 进度环**：`stroke-dasharray=周长`，`stroke-dashoffset` 用 800ms cubic-out 补间；**阶段切换瞬间 duration:0 归位**（不回放动画）。这是番茄钟"满足感"的核心视觉。
- 适配我们的方向：我们没有固定时长番茄，但**休息预算是天然的进度域**——离开休息时渲染一个「休息进度环」，按 `awaySeconds / restPlan.recommendedSeconds` 填充，到期变琥珀、逾期变红，把抽象的"已休息 3 分钟"变成可见的额度消耗。

### 2. Magic UI：脉冲环（pulsating）
- 实现：`box-shadow: 0 0 0 0 → 0 0 0 8px` 扩散，`ease-out`（ripple 变体用 `cubic-bezier(0.16,1,0.3,1)`，即 expo-out）；脉冲色默认从按钮背景色用相对色（oklch）派生 50% 透明度——**零配置跟随主题**。
- 适配我们的方向：L3「回到专注」CTA 目前只有浮沉，加一圈向外扩散的脉冲环，召唤感显著增强；纯 CSS、无库。他们默认周期 1.5s，按我们的呼吸纪律放慢到 `--dur-breathe`（2.4s）。
- confetti 用 canvas-confetti（Web Worker 渲染）：效果热闹但需要引库，且与沉浸学习气质冲突——**不采用**，我们的结束卡光晕绽放是更克制的等价物。

## 落地建议（按性价比排序）

> 2026-08-24 三项全部落地（复刻优先、二次开发）：

1. **【已移除】CTA 脉冲环**：曾复刻 Magic UI 的 ripple 变体；2026-08-25 用户确认它与既有开始/继续语义重复，已删除，保留此记录作为取舍依据。
2. **【已上线】休息进度环**：`RestRing` 复刻 Pomotroid `TimerDial.svelte` 的 dasharray/dashoffset 结构（周长 2πR、`stroke-linecap: round`、从空到满），svelte tweened 800ms 补间改 CSS `transition: stroke-dashoffset var(--dur-glide) linear`（每秒 awaySeconds tick 驱动，连续扫描无跳变）；渲染于三处 away-line 胶囊内，颜色随 `data-away-level` 中性→琥珀→红。实测：暂停 2.5s 后弧长 2.5% ✓。
3. **【已上线】结束卡数字滚动**：`DurationTicker` 复刻 Magic UI number-ticker 的 `useMotionValue + useSpring(damping 60, stiffness 100)`，二次开发为整数秒 → `formatDurationZh` 中文格式；实测 2→4→5→6 秒收敛 ✓。
4. 不做：confetti/彩带（需 canvas 库、气质冲突）、>1.5s 的快速脉冲、任何新依赖。
